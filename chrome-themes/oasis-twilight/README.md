# Oasis Twilight Chrome Theme

Unpacked Chrome theme using the same Oasis Twilight palette as the rest of this
dotfiles repo.

## Install

1. Open `chrome://extensions`.
2. Enable `Developer mode`.
3. Click `Load unpacked`.
4. Select this folder: `chrome-themes/oasis-twilight`.

To remove it later, go to `chrome://settings/appearance` and reset the theme.
