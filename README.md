# Dotfiles

Personal configuration files for development setup.

## Tools

- **Tmux:** Terminal multiplexer for managing multiple terminal sessions.
- **Zsh:** Z shell, an extended version of the Bourne shell with many improvements
- **Lazygit:** A simple terminal UI for git commands.
- **Neovim:** A hyperextensible Vim-based text editor.

## Setup

1. Install all the tools above

2. Copy the configuration files to your config directory:

```bash
cp -r kitty/ nvim/ tmux/ ~/.config/
cp .zshrc ~/
```
